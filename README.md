
This repository holds STL models downloaded from the Meshy AI community section.

### meshyai-categories
Each category within this folder holds around ~35 models

### category_query
The `category_query.py` file holds a script for the thingi10k dataset. It is meant to identify what unique subcategories lie under each category and examples names of the models within this overall category to guide our search of meshy ai models.
The `category_query_output.txt` holds the results of  running the script on the thingi10k dataset.
